Body

Top-level RDF classes named Thing, as imported/created by AboutMVF.rdf and its sub-ontologies, which have explicit relationships to other versions of Thing

Also shows the class MVFElement, which has been added as part of this metamodel based on the PDF version of the MVF specification, which forms the basis for the profile definition.
