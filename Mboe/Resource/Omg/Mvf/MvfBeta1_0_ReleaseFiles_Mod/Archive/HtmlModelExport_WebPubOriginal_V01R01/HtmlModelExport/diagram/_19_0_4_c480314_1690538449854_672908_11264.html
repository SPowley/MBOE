Diagram MVF Metamodel - Side by Side (RDF vs PDF/XMI)

Comment

The full MVF metamodel based on the RDF specification Multiple Vocabulary Facility (MVF) Ontology alongside the XMI/PDF version.

The RDF version is imported by AboutMvf.rdf specification differs from the metamodel based on the PDF specification, see MVF Metamodel - Per PDF (no missing elements), which in turn differs from the imported XMI version of the model, see MVF Metamodel - Per XMI (missing elements). This diagram shows the two versions of the metamodel alongside each other.

 

For mappings between the classes belonging to each version, see MVF Metamodel - RDF to XMI/PDF equivalent class mappings.
