The subproperties of the SKOS mappingRelation that are used as the basis for traceability to the RDF by mappingRelation - SKOS to profile mapping


Only mappingRelations (i.e. those that apply between vocabularies) are shown on this diagram, the other semantic relation subtypes are omitted.

Note that this means all transitive relations are omitted except from skos:exactMatch (on this diagram the role 'has exact match') is a transitive property in SKOS, see SKOS mapping properties in the SKOS specification). It is important for MBOE that the other mapping relations are not assumed to be transitive as this could lead to false inference.

 

Due to the fact that not all semantic relations are implemented in the UML profile as associations, it is not possible to represent them in this model as subsetting relations of the 'is in mapping relation with' attribute. This is because doing so would impose the properties of the UML association onto elements unnecessarily that are not best modelled in UML as associations, for example, dependency relations, such as adopted by. For more detailed information on this issue, see diagram info for MVF Metamodel - Assertions for joining MVF with SKOS Extensions

 

For the diagram showing the full set of semantic relations defined by SKOS, see SKOS Metamodel - Per RDF (no annotations)
