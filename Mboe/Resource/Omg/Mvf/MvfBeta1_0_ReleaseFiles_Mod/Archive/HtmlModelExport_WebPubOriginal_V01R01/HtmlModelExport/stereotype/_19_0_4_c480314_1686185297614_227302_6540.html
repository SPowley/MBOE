Stereotype workspace

Comment
A workspace is an MVF element that references a consistent set of the MVF dictionaries and vocabularies to be used in
in a modeling environment. It’s the responsibility of a conformant modeling tool to select the current active Workspace, which is then used to resolve from a Model Element to the most appropriate Vocabulary Entry to provide the term and definition.
