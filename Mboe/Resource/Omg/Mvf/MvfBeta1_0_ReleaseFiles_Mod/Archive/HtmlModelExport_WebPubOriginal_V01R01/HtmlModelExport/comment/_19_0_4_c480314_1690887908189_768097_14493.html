Definition of the basic metamodel element MVFElement and its properties

MVFElement is the base element in the MBOE metamodel, and shows mappings from MVFElement to the top-level elements (all denoted Thing) that are imported by the AboutMVF.rdf Note that although the SKOS core ontology is a separate metamodel in this model, the vocabulary is also imported as standard by MVF.

Where possible, class attributes used in this model are inherited from the already loaded RDF ontologies to provide maximum semantic web compatibility. This also avoids introducing reliance on any RDF ontologies other than those already imported by MVF.
