Body

Shows the various versions of the top-level class Thing that are imported/created by AboutMVF.rdf and its sub-ontologies.

«Equivalent Class» assertions are added to indicate that all these top-level elements are equivalent.

To reduce the number of assertions, the RDF schema acts as a hub for the equivalence is a transitive property in SKOS . This is sufficient because equivalence is transitive see skos:exactMatch

For relationships and properties of Things, see diagrams: MVF Metamodel - Relationships between Things that have inter-relationships and

MVF Metamodel - Relationships between Things with only reflexive relationships
