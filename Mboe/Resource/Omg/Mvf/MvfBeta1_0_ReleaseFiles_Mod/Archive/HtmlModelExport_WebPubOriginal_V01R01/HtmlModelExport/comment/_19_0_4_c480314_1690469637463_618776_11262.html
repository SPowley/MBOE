The main MVF metamodel based on Multiple Vocabulary Facility (MVF) Ontology.

This the main MVF ontology, which is one of the ontologies loaded by the imported AboutMvf.rdf.

 

This differs from the metamodel based on the PDF specification, see MVF Metamodel - Per PDF (no missing elements), which in turn differs from the imported XMI version of the model, see MVF Metamodel - Per XMI (missing elements) and MVF Metamodel - Side by Side (RDF vs&nbsp; PDF/XMI). Theoretically all versions should all agree. For the resolution stategy see: MVF Metamodel - Per PDF (no missing elements).
