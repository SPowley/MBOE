General Information
Owner  mvfContext  
Applied Stereotype  Literal Annotation
Annotated Element  mvfContext
Body Custom extension to MVF to provide a structured format for context setting questions.
Note: This is currently implemented as simple text strings, but ideally the context attributes would be references to model elements that provide richer information and interrelationships e.g. create an ontology for modelling "who" that provides a structure for people and organizations and how they are related. This is an emerging field of study and the approach here is informed by the OMG's Vocabularies for Communities of Interest (VCoI) project.
